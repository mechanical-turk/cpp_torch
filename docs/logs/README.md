# Append-Only Logs

Files in this directory preserve chronological observations and experiments.

- Append new dated entries at the end.
- Do not silently rewrite an old observation after later evidence changes the
  interpretation. Add a new entry that corrects or supersedes it.
- Put detailed analysis in a dated analytics report and link it from the log.
- Promote only durable, supported conclusions into an operating playbook.
- Do not copy ledger entries into `AGENTS.md`.
