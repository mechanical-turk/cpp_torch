# Decision Records

Use this directory for decisions whose consequences span multiple milestones.
Local implementation choices belong in the relevant milestone record.

Each decision record should state:

- the context and concrete problem;
- the alternatives considered;
- the evidence available at the time;
- the decision and its rationale;
- expected consequences and risks;
- what would justify revisiting it; and
- which learning-plan sections or milestones it affects.

Do not rewrite history when a decision changes. Add a superseding record and
link the two.
