2160×2300; these are motion/concept candidates, not native final exports.
Full-resolution expansion waits for creator feedback. Previous final-v2 files
remain intact for reference and are superseded for the affected visuals.

- White outlines identify the active source, chosen bucket and scanned array key.
- Five source attempts remain 3,1,3,2,1. New keys land; matching duplicates
  compare above the occupied well and squash away. Three stored keys remain.
- The three wells depict the destinations used by these values, not all buckets,
  a literal hash function, capacity or a measured memory-address layout.
- Original sort/unique motion, spoken words, code and benchmark remain unchanged.
- The cyan retained-range divider is deleted, including later scene holds.

  claiming a measured pointer trace. Scene 07 clears the old wells before
  showing the unmeasured flat-table concept.

Files retain numbering 01–07 and the previous editable durations. Native clay,
lighting and camera are inherited. The preview profile is Cycles/OptiX at 16
samples, full frame at 10%, with two-frame holds and no interpolated frames.
No native-resolution plates are generated during this preview run.

actual completed exports. Preview frames/logs stay on the authorized worker;
editable source, reports and completed clips are delivered here in Content HQ.
