# Short 07 — hand-sculpted clay study, revision 2

September 9, 2026 follow-up to the extreme clay sample. The creator rejected
radial surface artifacts and asked for a more pronounced clay treatment.

All fingerprint/radial-wave shader construction is removed. Clay materials use
only nonperiodic pigment variation, stretched noise smears and restrained fine
grain. The principal change is actual geometry: dense rounded-rectangle lofts
with fuller rolled crowns, widely spaced thumb compressions, small displaced
bulges and localized soft folds. Counter/core shells share one master, the two
trays share another, and path pills share a pinched master. Physical lettering
has more rounded raised depth; camera-parented syntax-highlighted code is intact.

The palette, layout and native 2160 × 2300 canvas come from approved final-v8
frame 551. A separate 2160 × 3840 proof uses the actual platform overlay at 2×.
The existing completed videos and first look study remain separate.

Run `build_sample.py` for a 50% native preview; add `-- --final` under Blender
for the editable scene and full-size clay/code passes. Run `finish_sample.py`
with system Python/Pillow for the sample, proof and verification record.
All generated outputs stay in this episode assets package and are Git-ignored.
This remains a single-frame appearance study, not approved replacement motion.
