# Short 07 — extreme handmade clay study

Superseded: the creator rejected the radial marks in this sample as glitch-like.
The corrected follow-up is in `../extreme-clay-study-v2/`; do not reuse this
fingerprint shader for future work.

A separate native Blender still study requested September 9, 2026. Uses the
approved Short 07 frame 551 layout at 2160 × 2300 and the existing Retro Sunset
teal/cobalt/orange palette. This is an appearance experiment, not an approved
replacement for the completed six revision 8 videos.

The material stack emphasizes broad kneading, localized partial fingerprint
ridges, shallow thumb impressions, pigment variation and restrained fine grain.
A canonical mesh deformation adds compressed, uneven rims; corresponding
counter and tray meshes remain linked. The flow pills use a shared pinched
master. Roughness variation, slight subsurface scattering and directional
studio light show the sculpting while leaving the code and labels readable.

Early complete concentric impressions looked artificial. The final treatment
uses broken, distorted arcs with tapered coverage, away from the main lettering.
The code remains in its approved inline-alignment layout with unchanged placement.
The actual platform template is doubled over the complete 2160 × 3840 master
for a separate proof; the guide is never included in the sample itself.

`build_sample.py` loads the approved scene, freezes one pose, creates this look,
and renders native clay and code passes. `--final` saves the editable study and
renders at native size with 192 Cycles samples for the clay and 64 for code.
`finish_sample.py` composes the native passes, creates the template proof and
records image verification. Render work stays in `_render/` beside the source.

No video, timeline or existing approved render is replaced. No motion or clay
physics is demonstrated by this still. The study has not been promoted into the
standing animations playbook.
