# Retro Sunset object studies

Retro Sunset is the user-selected theme going forward for this visual family.

Three object-design samples generated with the built-in ImageGen tool:

1. Soft enamel: rounded golden score tiles, recessed amber faces, rounded blue card cartridges.
2. Precision hardware: chamfered gold modules and structured navy/cobalt cassettes.
3. Playful soft-touch: pillowy gold keycaps and softly rounded cartridge cradles.

These are form/material concepts. Generated card counts vary and are not production-accurate; the eventual Blender implementation must retain all fifteen history elements per player and verified placement. Code and field labels are readable in the samples. No object direction has been selected yet. The existing Blender scene and video remain unchanged. Prompts are preserved in prompts.json.
